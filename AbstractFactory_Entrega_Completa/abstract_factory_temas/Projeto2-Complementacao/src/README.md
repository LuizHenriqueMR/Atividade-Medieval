# Projeto 2 - Complementação do Abstract Factory

Complementação com:
- tema Fantasia
- terceiro produto da família: Transporte

```bash
javac game/MainProjeto2.java game/factory/*.java game/personagens/*.java game/armas/*.java game/transportes/*.java
```

## Como executar
```bash
java game.MainProjeto2
```

Exemplos de entrada:
- medieval
- futurista
- fantasia
